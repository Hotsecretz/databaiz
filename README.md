# databaiz
AI powered tool for the newsroom
DatabAIz v1 is a locally-hosted, multi-source monitoring and lead-generation dashboard for small investigative and OSINT newsrooms.
Editors and reporters at small, resource-constrained investigative and OSINT newsrooms want to continuously monitor public data sources so that they receive timely, structured story leads. They are scored for urgency, novelty, and accountability. DatabAIz surfaces these leads as a news alert and a pitch sheet on a local dashboard, enabling editorial teams to plan investigative, long-form, and OSINT content ahead of the news cycle.
